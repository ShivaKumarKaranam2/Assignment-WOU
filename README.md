# Claims Agentic Health

Health insurance claims processing app built with a single LangGraph workflow, FastAPI, Streamlit, LangSmith tracing, and NVIDIA OCR/LLM endpoints.

## Run

```bash
uv sync --extra dev
uv run claims-api
uv run claims-ui
uv run pytest
```

## Environment

Copy `.env.example` to `.env` and set the NVIDIA credentials.
